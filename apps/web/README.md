# apps/web — front do TroKa

Vite + React 19 + TanStack Router (SPA) + Tailwind 4 + shadcn/ui. Deploy: Vercel (`vercel.json` faz o fallback da SPA).

```bash
cp .env.example .env.local   # preencha com `npx supabase status` (raiz)
npm install
npm run dev                  # http://localhost:5173
```
